# Generative AI with LLMs Course

This repository contains my work from the [DeepLearning.AI Generative AI with LLMs course](https://www.coursera.org/learn/generative-ai-with-llms).

## Course Overview

Learn the fundamentals of how generative AI works and how to deploy it in real-world applications. The course covers:

- Understanding generative AI and LLM lifecycle from data gathering to deployment
- Deep dive into transformer architecture and training methodologies
- Applying empirical scaling laws for model optimization
- Using state-of-the-art training, tuning and deployment methods
- Exploring business challenges and opportunities with generative AI
